# Arceus detail fixture

Normalized public PokéAPI #493 metadata from 2026-11-13, filtered to BW2 learn methods
by `PokeAPIClient.normalizedMoves`. Contains 106 base learnset moves and no user data.
Fairy exceptions are merged by the production code. This fixture keeps detail-page
performance tests on the full learnset rather than a three-move stub.

Source: https://pokeapi.co/api/v2/pokemon/493/
