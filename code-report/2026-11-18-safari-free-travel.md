# 사파리존 자유 지역 이동 (2026-11-18, 3.2.3)

## 결정 (사용자)
- 지역 이동 제한(최대 2개 지역, 지역당 볼 10개, 무작위 후보 3곳)을 없애고 "지역 이동" 버튼으로 언제든 이동.
- 조우 중에도 이동 가능 — 마주친 포켓몬은 도망 가기처럼 떠나고 볼은 쓰지 않는다.
- 고르는 화면은 대표 포켓몬 카드 격자(취소 가능). 볼 20개를 다 쓰면 종료되는 규칙은 유지.

## 구현 근거
- **규칙은 세션 값 타입 한 곳에.** `SafariSession.travel(to:catalog:)` 가 조우를 끝내고(보정값 초기화) 지역을
  바꾼 뒤 `continueJourney` 로 첫 포켓몬을 만든다. 같은 지역으로의 이동은 거부해 "제자리 재추첨"을 막는다.
  다른 지역 이동으로 새 포켓몬을 받는 것은 기존 "도망 → 계속 탐험"과 같은 수준이라 새 악용 경로가 아니다.
- **저장 호환.** 규칙 버전 4. 이전 버전(nil/2/3)은 이동 대기 상태와 지역당 계수만 지우고 포획·교체 선택·
  볼 수·진행 상태를 보존한다. 예전 이관은 3번째 지역 기록이 있으면 탐험을 끝냈지만, 제한이 사라졌으므로
  이제는 계속 진행한다(의도된 변화). 미래 버전 저장은 이관하지 않고 검증에서 거부한다.
- **화면.** 이동 버튼은 종료 왼쪽. 포획 연출·교체 선택·종료 후에는 잠근다. 선택 창이 열린 동안 1.2초 자동
  진행을 멈추고, 취소하면 다시 건다. 이동 직후 새 포켓몬에도 0.5초 클릭 잠금이 그대로 걸린다.

## 작업 중 발견한 결함
- **네이티브 버튼 비활성화가 무시됨.** `SafariFinishButton` 이 스스로 `isEnabled=false` 를 해도 감싼 SwiftUI
  `.disabled(false)` 가 다시 켰다. 기존 "종료" 버튼도 교체 선택 중 눌렸고(저장소가 거부해 오류 문구만 표시),
  새 이동 버튼이었다면 선택 창 없이 화면 전체가 잠겼다. 두 버튼에 SwiftUI `.disabled` 를 함께 걸고,
  이동 동작은 누를 때 다시 확인한다. defect-log 에 기록.
- **긴 지역 이름 겹침(리뷰 지적, 렌더링으로 확인).** 러시아어에서 지역 이름 버튼이 옆 카드를 덮었다.
  이름은 줄바꿈되는 글자로, 버튼은 짧은 "선택"으로 바꿔 8개 언어 모두 겹침 0을 측정했다.

## 검증
- 새 테스트: 세션 이동 규칙 6개, 화면(버튼→창→취소→확정→저장 유지, 교체 중 두 버튼 잠금),
  선택 창이 자동 진행을 멈추고 취소가 재개하는지. 옛 규칙 전용 테스트 10개는 제거, 이관 테스트는 새 설계로 갱신.
- 비활성화 수정 2곳과 이관 버전 조건·자동 진행 재시작은 결함 주입/선행 실패로 테스트가 잡는 것을 확인.
